## 检索策略

- 需要外部检索时，先使用 Codex 内置搜索。
- 存在本地仓库时，在外部检索前后检查已有文献并去重。
- 仅在用户明确要求、内置搜索不足/不可用、垂直搜索明显增益或高准确性任务需要独立复核时使用 AnySearch。
- 记录实际使用的渠道、查询、日期、结果、冲突和剩余缺口；只有必需渠道未完成时才降低状态。

## 来源与论文层级

- 以具体主张的正文支持、相关性、方法、验证和边界为准入核心。
- 期刊/会议层级不能替代正文核验，也不能在项目未设层级门时成为一票否决条件。
- 当层级影响来源选择或项目政策时，记录评价体系、年份、核验日期、证据链接和判断理由。
- 主方法来源必须直接相关、方法可重构、验证充分并优于备选；仅在项目明确要求时执行 `top/high` 门。

## 引用与内容所有权

- 关键方法、数据、机制、限制和标准要求必须就近引用。
- 文献事实、本项目综合判断/设计、待验证假设必须显式区分。
- 只读过摘要、搜索片段或二手转述的来源不得支撑方法性强结论。

## 公式

- 每个展示公式后立即给出“式中”说明或唯一紧邻的符号表。
- 解释全部变量、函数、常数、索引、上下标、集合、算子、单位和正负号。
- 符号未闭合时不得标记为论文级、定稿或可交付。

## 原始资产

- `raw/` 中的原始文件不可覆盖。
- 正式 Markdown 必须使用可点击的相对链接。
- 复用仓库已有全文，不重复复制二进制文件。
